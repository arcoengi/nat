КАК ПОСМОТРЕТЬ
Откройте index.html после распаковки всей папки.

КАК ЗАГРУЗИТЬ
В корне репозитория нажмите Add file → Upload files.
Загрузите СОДЕРЖИМОЕ этой папки, сохранив вложенность assets.
Не загружайте папку nat целиком внутрь одноимённого репозитория.
Подтвердите Commit changes и дождитесь успешной публикации GitHub Pages.
Если .gitattributes не загружается: Add file → Create new file,
имя .gitattributes, содержимое одной строкой: *.vcf -text

ЧТО ОБНОВЛЕНО
Дизайн и заставка как у Регины. Заставку можно пропустить нажатием или Escape.
Кнопки звонка, почты и личного Telegram, копирование номера и почты.
QR-кода и кнопки «Поделиться» нет. Ссылки компании сохранены.
Файл Natalya_Babina.vcf — готовый vCard 3.0 с русским именем, должностью,
телефоном, почтой, адресом, сайтом, Telegram компании и личным Telegram.
Сохранение работает без JavaScript. Для проверки импорта откройте сайт
на телефоне в Safari или Chrome. Сам сайт не может подтвердить импорт
в адресную книгу — создание контакта завершает пользователь на телефоне.

ПРОВЕРКИ
Проверены код, локальные ресурсы, совпадение данных HTML и vCard,
UTF-8, CRLF и разбор файла контакта. Физические телефоны и браузерная
анимация в этой среде не проверены.
